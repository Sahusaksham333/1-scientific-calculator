## 📌 Project Overview

**1-Scientific-Calculator** is a clean, interactive **web-based scientific calculator** built using **Python and Streamlit**.
The goal of this project is not just calculation, but **hands-on learning, deployment practice, and consistency**.

This application supports both **basic arithmetic** and **scientific operations**, making it a strong foundation project for larger mathematical and AI-driven tools in the future.

---

## ✨ Features

* ➕ Addition (supports multiple values)
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division (with zero-division handling)
* 🔢 Power calculations
* 📐 Trigonometric functions (sin, cos, tan)
* 🧠 Logarithmic & square-root operations
* 🎛️ User-friendly interactive UI
* 🌐 Deployed and accessible online

---

## 🛠️ Tech Stack

| Technology          | Usage                        |

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone <your-repo-link>

# Move into the project directory
cd 1-scientific-calculator

# Install dependencies
pip install streamlit

# Run the app
streamlit run app.py
```
